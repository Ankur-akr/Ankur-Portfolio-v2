# 🌐 Ankur Kumar Rai - Developer Portfolio

A modern, responsive, and interactive portfolio website built to showcase my skills, projects, and experience as a Computer Science and Engineering student.

---

## 🚀 Features

* 🎨 **Modern UI/UX Design** – Clean, professional, and recruiter-friendly layout
* 🌙 **Dark Mode Support** – Toggle between light and dark themes
* 🎬 **3D Hero Section** – Interactive animated hero with typing effect
* ✨ **Particle Background** – Dynamic canvas-based animation
* ⚡ **Smooth Animations** – Scroll and hover-based transitions
* 📱 **Fully Responsive** – Works across all devices
* 🧠 **Structured Content** – Projects, skills, experience, and achievements

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Tailwind CSS
* **JavaScript:** Vanilla JS (animations, interactivity)
* **UI/UX:** Custom CSS + modern design principles
* **Icons & Fonts:** Font Awesome, Google Fonts
