## 🚀 Overview

Welcome to my personal portfolio! This website serves as a central place to explore my development journey, technical expertise, and the projects I've built.

Designed with a focus on **modern UI/UX, smooth animations, responsiveness, and accessibility**, the portfolio reflects my passion for building interactive web experiences and solving real-world problems through technology.

## ✨ Features

- 🎨 **Modern UI/UX** — Clean, professional, and recruiter-friendly design.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 🎬 **Interactive Hero Section** — Engaging animations and a dynamic typing effect.
- ✨ **Particle Background** — Canvas-based visual effects for an immersive experience.
- ⚡ **Smooth Animations** — Interactive transitions, scrolling effects, and hover animations.
- 📱 **Fully Responsive** — Optimized for desktops, tablets, and mobile devices.
- 🧩 **Project Showcase** — Highlights personal projects, technologies, and key features.
- 💻 **Technical Skills** — Organized overview of my programming languages, frameworks, and tools.
- 🏆 **Achievements & Experience** — Showcases milestones, accomplishments, and professional experience.
- 📬 **Contact & Social Links** — Easy access to my professional profiles and contact information.
